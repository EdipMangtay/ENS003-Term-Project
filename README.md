# Hip Implant Surrogate ML

A surrogate model for a Ti-6Al-4V (annealed) cementless hip-implant stem,
trained on ANSYS Static Structural simulations. Given a patient mass, a
body-weight multiplier (K), and a force tilt angle, the model predicts
three minimum safety factors (neck, STEM 1, STEM 2), peak stresses, and
total deformation in milliseconds. A LaTeX-styled, responsive Flask web
app renders the prediction and contrasts it with the underlying FEA data.

Primary model: **Gaussian Process Regression** (RBF + white-noise kernel),
chosen after a head-to-head benchmark against XGBoost and Kernel Ridge
on the full 270-row dataset.

## Setup

brew install libomp

## Usage

```bash
./run.sh check                                       # show the dataset
./run.sh convert                                     # raw → data/dataset.csv
./run.sh train                                       # retrain every target
./run.sh predict --mass 70 --k 2.5 --angle 0         # CLI inference
./run.sh predict --mass 80 --activity stair_climbing # activity preset → K
./run.sh app                                         # Flask web app at http://localhost:5050
```

When new FEA runs arrive, replace `Ti64_Hip_Implant_Dataset.csv` (or
`.xlsx`) and re-run `./run.sh convert && ./run.sh train`.

## Dataset

ANSYS Workbench parametric sweep of three inputs:

- **Mass:** 50, 60, 70, 80, 90, 100 kg
- **K (body-weight multiplier):** 2, 2.5, 3, 3.5, 4, 4.5, 5, 5.5, 6
- **Angle (force tilt in xz-plane):** 0°, 10°, 20°

The grid produces **162 unique design points**. ANSYS additionally re-ran
108 of them after a project update; the duplicates differ only at the
5th–6th significant figure (solver micro-noise). We keep all 270 rows so
every solve contributes to training, and use **5-fold cross-validation
grouped on `(mass, K, angle)`** so duplicates never leak between train
and test folds.

Force components are derived from the grid:
`Fx = mass · g · K · cos(angle)`, `Fz = mass · g · K · sin(angle)`,
`Fy = 0`. Native units MPa / mm; the converter normalises them to Pa / m.

## Feature engineering (`src/preprocess.py`)

Inputs:
- `patient_mass_kg`, `K_factor`, `force_angle_deg`

Derived:
- `force_x_N`, `force_z_N`, `force_magnitude_N` — recomputed analytically
  so train-time and predict-time always use the same formula.

`force_y_N` and `fixed_support_n_faces` are constant across the grid
(uniaxial xz-plane load, 18-face fixed support) and are not exposed as
model inputs.

## Predicted targets

| Target | Definition | Unit |
|---|---|---|
| `safety_factor_neck_min` | Min SF at the implant neck region | – |
| `safety_factor_stem1_min` | Min SF on stem region 1 | – |
| `safety_factor_stem2_min` | Min SF on stem region 2 | – |
| `max_equivalent_vonmises_stress_Pa` | Peak von Mises stress | Pa |
| `avg_equivalent_vonmises_stress_Pa` | Mean von Mises stress | Pa |
| `min_equivalent_vonmises_stress_Pa` | Min von Mises stress (≈ FEA noise floor) | Pa |
| `max_principal_stress_Pa` | Peak maximum-principal stress | Pa |
| `avg_principal_stress_Pa` | Mean maximum-principal stress | Pa |
| `min_principal_stress_Pa` | Most-compressive principal stress | Pa |
| `max_total_deformation_m` | Peak total deformation | m |

## Model

**Gaussian Process Regression** (scikit-learn) with a
`Constant × RBF + WhiteKernel` kernel and `normalize_y=True`, wrapped in
`TransformedTargetRegressor(StandardScaler())`. The hyperparameters
(length scale, signal variance, noise level) are fit by maximum-likelihood
with 5 random restarts. The posterior is closed-form, so every prediction
comes with a calibrated standard deviation.

Why GPR rather than XGBoost (head-to-head on 270 rows, target = SF_neck):

| Model | R²_CV | MAE_CV | Smoothness (51-mass sweep) |
|---|---|---|---|
| XGBoost stumps (max_depth=1) | 0.986 | 0.032 | 18 / 51 unique outputs |
| XGBoost depth=3 | 0.988 | 0.024 | 27 / 51 unique outputs |
| Kernel Ridge (RBF) | -0.005 | 0.369 | 5 / 51 unique outputs |
| **GPR (RBF + white)** | **0.9999** | **0.00077** | **51 / 51 (continuous)** |

Tree-based methods on 162 unique training points still produce
piecewise-constant outputs; GPR fits a closed-form posterior over functions
and interpolates continuously across the whole input space.

Fallback chain: GPR → XGBoost → sklearn-GBR.

## Evaluation

5-fold cross-validation **grouped on `(mass, K, angle)`** so ANSYS re-runs
of the same design point never leak between train and test folds. Without
this, R² would inflate artificially toward 1.0. `models/metrics.json`
stores R², MAE and the winning model per target after every training run.

| Target | R²_CV | MAE_CV |
|---|---|---|
| safety_factor_neck_min | 0.9999 | 7.7×10⁻⁴ |
| safety_factor_stem1_min | 0.9999 | 8.3×10⁻⁴ |
| safety_factor_stem2_min | 0.9997 | 4.4×10⁻³ |
| max_equivalent_vonmises_stress_Pa | 0.9998 | 0.53 MPa |
| avg_equivalent_vonmises_stress_Pa | 0.9998 | 10.6 kPa |
| max_principal_stress_Pa | 0.9998 | 0.57 MPa |
| avg_principal_stress_Pa | 0.9998 | 5.0 kPa |
| min_principal_stress_Pa | 0.9998 | 0.15 MPa |
| max_total_deformation_m | 0.9998 | 7.4×10⁻⁷ m |

`min_equivalent_vonmises_stress_Pa` sits at ≈10⁻¹⁰ Pa across the entire
grid — it is the FEA solver noise floor, not a useful target. It is
included in the model set for completeness but R²_CV ≈ 0.03 and it is
hidden from the dashboard.

## Data sources

- **`Ti64_Hip_Implant_Dataset.csv` / `.xlsx`** — 270 ANSYS Static
  Structural design points (162 unique grid points + 108 ANSYS re-runs
  that differ only by solver micro-noise). All 270 are kept so every
  solve contributes to training. Native units MPa / mm; the converter
  normalises them to Pa / m.
- **`Analiz_Raporu_Tek_Sayfa.xlsx`** — ANSYS model constants
  (86 087 nodes, 43 967 elements, V = 49 298 mm³, m = 0.218 kg,
  Ti-6Al-4V, E = 104.8 GPa, σ_y = 827 MPa, σ_u = 918 MPa). Frozen inside
  `ModelConstants` in the converter.

## Known limitations

- `force_y_N` is zero across the entire training set; out-of-plane
  loading is not modelled.
- The 18-faced fixed support is constant; different fixation patterns
  (12-face, distal fixation, etc.) would require a new FEA grid.
- Interpolation inside the grid is reliable; extrapolation (mass < 50 kg,
  K > 6, angle > 20°) should be treated with care.
